# 🔢 Counter App

A simple and interactive Counter App built using **HTML, CSS, and JavaScript**. This project allows users to increase, decrease, and reset a counter with a clean and user-friendly interface.

## 🚀 Features

* ➕ **Increase Counter:** Increment the counter by 1.
* ➖ **Decrease Counter:** Decrement the counter by 1.
* 🔄 **Reset Counter:** Reset the counter to zero.
* 🎨 **Clean UI:** Attractive design with a gradient background.
* ✨ **Hover Effects:** Smooth button hover animations.
* 📱 **Responsive Layout:** Flexible layout for different screen sizes.

## 🛠️ Technologies Used

* **HTML5** — Structures the application.
* **CSS3** — Styles the interface and adds hover effects.
* **JavaScript** — Handles counter logic and button interactions.

## 💡 How It Works

1. The counter starts at `0`.
2. Clicking the **Increase** button increments the value by one.
3. Clicking the **Decrease** button decrements the value by one.
4. Clicking the **Reset** button sets the value back to zero.
5. JavaScript updates the displayed value dynamically without reloading the page.
